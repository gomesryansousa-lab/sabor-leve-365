# Sabor Leve 365 — Página de vendas

Landing page **Cozinha Leve — 365 Receitas Sem Açúcar, Sem Glúten e Sem Lactose**.

## Como abrir
O site está no arquivo `index.html`: contém HTML, estilos CSS, scripts e imagens embutidas. Abra no navegador ou importe o repositório em um projeto estático no Vercel (diretório raiz, sem build).

## Antes de divulgar ou vender
- Configurar os links **reais** de checkout dos dois planos. Os botões de compra são demonstrações.
- Revisar e testar todas as receitas, inclusive ingredientes, alergênicos e riscos de contaminação cruzada.
- Confirmar que os materiais anunciados (365 receitas e bônus) existem e serão entregues.
- Ajustar a política de garantia e as condições de entrega no texto.
- Incluir somente depoimentos, métricas e promoções verdadeiros; a prévia não contém avaliações comerciais verificadas.

**Status:** código enviado ao GitHub; **não significa que a página esteja publicada em um domínio ou com pagamentos habilitados.**
